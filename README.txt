Timi Loves You
===============

For the most reliable video playback, open a terminal in this folder and run:

  python3 -m http.server 8000

Then visit http://localhost:8000. Some browsers restrict local video playback
when index.html is opened directly with a file:// URL.

Features:
- Multi-step apology experience with Spotify track and a final Continue button to the personal website
- Supplied animated cat video on the apology pages
- Responsive romantic landing page
- Rotating love messages and reasons
- Local bedtime preference
- Cycle calendar display
- Current date shown using West Africa Time (Africa/Lagos), updated whenever the site is opened
- Open-when letters
- Private notes saved in the current browser
- Mood check-ins saved in the current browser
- Local image and video previews
- Paste images and videos directly into the page to add them to Memories

Images and videos are previewed in the current browser only. They are not
uploaded or stored online.
